localCAI

Drop .lcai.json, CAI Tools / SillyTavern files, character cards or a .zip anywhere.

Bring your characters home.

  1. Install the localCAI Extractor browser extension, open your chat on Character.AI and click Export .lcai.json.
  2. Drag the file into this window (or use Import files).
  3. Start a local model runner (Ollama, LM Studio, llama.cpp, KoboldCpp), pick it in the top bar and chat.

Everything stays on this computer. Not affiliated with Character.AI.
