## localCAI v0.8.3 · Extractor 0.5.0

**Bring your Character.AI characters home** and keep chatting with them on a local AI.

### Downloads
- **`localCAI.exe`**: the Windows app. Double-click to open; it runs in its own window with no console and doesn't need Python. Windows may warn that it's from an unknown publisher (the exe isn't code-signed yet): click *More info* → *Run anyway*.
- `localcai-extractor-0.5.0-chrome.zip`: browser extension for Chrome / Edge / Brave
- `localcai-extractor-0.5.0-firefox.zip`: browser extension for Firefox 140+ (and Firefox for Android 142+)
- **Source code (zip)**: the app for macOS/Linux, or Windows without the exe. Unzip and double-click `start-localcai.sh` / `start-localcai.bat`. Needs Python 3.10+.

### Install the extension (until it's in the stores)
**Chrome / Edge / Brave:** unzip the Chrome zip → open `chrome://extensions` → turn on *Developer mode* → *Load unpacked* → pick the unzipped folder.
**Firefox:** open `about:debugging#/runtime/this-firefox` → *Load Temporary Add-on* → pick the Firefox zip.

### Highlights
- **Desktop app**: its own window with the localCAI logo in the taskbar
- ⏫ **Load full history**: tens of thousands of messages in about a minute
- Exports chats, swipes, pins, C.ai chat memory, personas, avatars and backgrounds
- App with a **built-in llama.cpp engine** (no Ollama needed) and a model slot for any `.gguf`
- C.ai-style tools: ◀ ▶ swipes, ✏ edit, 📌 pin, ⤺ rewind, 🖼 backgrounds, ✎ edit character
- 🔍 **Learn style** from your history, 📖 **chat memory** ("the story so far"), automatic recall of earlier moments
- Everything stays on your computer. See [PRIVACY.md](PRIVACY.md)
